# Synthetic demo data

Generated by `scripts/synthetic/generate.ts`. These files are fictional and
are not loaded into Piezas automatically.

Regenerate with a chosen timestamp for reproducible scenario times:

```sh
npx tsx scripts/synthetic/generate.ts --now 2026-11-08T03:00:00Z
```

Omit `--now` to use the current time. The generator rounds it down to the UTC
hour. Its fixed random seed is `20261107`; the scenario list is in
`scenarios.md`.
